# Changelog

## 1.0.0 — 2026-09-06

- Complete human-versus-CPU game on a 58-cell hexagonal board.
- Clone, jump, conversion, automatic passes, and terminal scoring.
- Three deterministic CPU levels, including alpha-beta minimax in a worker process.
- Original 384x240 VGA pixel art, bitmap font, integer scaling, and fullscreen mode.
- Menu, instructions, pause, restart, debug overlay, animations, and synthesized sound.
- Automated tests, headless startup checks, screenshots, and GitHub Actions workflow.
- English documentation, MIT license, and reproducible source archive with SHA-256.
